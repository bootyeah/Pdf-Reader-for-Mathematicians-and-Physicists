# airtex · 手写公式识别（手机手写 / 电脑鼠标手写）

在**手机浏览器**上手写数学公式，**电脑上的半透明浮窗实时显示笔迹**；
也可以直接在电脑浮窗上**用鼠标写**。两种写法是**两套独立的模式**（点标题栏
「→鼠标 / →手机」切换），写好后点「识别」，调用免费视觉大模型
（智谱 GLM-4.6V-Flash）识别成 LaTeX，**电脑自动复制到剪贴板**，
识别结果仅在电脑显示和复制，手机保持书写画布。

```
① 手机手写模式（默认）
手机浏览器手写  ──Wi-Fi──▶  电脑半透明浮窗（实时同步，自动放大笔迹填满窗口）
        │                            │
        └──── 点「识别公式」──────────▶  GLM 视觉模型
                                     │
                                     └──▶  电脑显示结果、自动复制 LaTeX

② 鼠标手写模式（点浮窗标题栏「→鼠标」切换；此时手机端自动暂停）
电脑浮窗上直接用鼠标写  ──▶  同一块浮窗 1:1 显示（不缩放、不挪位）
        │
        └──── 点「识别」（或停笔后自动识别）──▶  GLM 视觉模型 ──▶ 自动复制 LaTeX
```

> **为什么分成两种模式而不是合成一个？**
> 手机手写时电脑端会「把有笔迹的那块区域放大铺满浮窗」（`canvas_view=fill`，
> 看着更清楚，也是送 AI 的同一块区域）。这个自动放大**没法**和鼠标书写共存：
> 一边写、画面一边被重新取景缩放，笔会「跑」。所以两种写法各用一块画布、
> 各管一套显示方式，切模式时两边的内容都原地保留、互不搬运。

## 快速开始

1. **双击 `run.bat`**（首次会自动安装 Pillow）。
   电脑右上角出现半透明浮窗，`airtex.log` 里会记录手机访问地址。
2. **点浮窗上的「二维码」**，用手机相机扫码打开（手机和电脑要在**同一个 Wi-Fi**）。
   - 首次连接若 Windows 弹出防火墙提示，选「**允许访问**」。
   - 也可以右键浮窗 → 「复制访问地址」，手动在手机浏览器输入。
3. 手机页面会**自动铺满书写区**，直接用手指写公式，电脑浮窗上会**实时出现同样的笔迹**。
4. 写完点手机上的 **「识别公式」**（或按浮窗上的「识别」，或直接点浮窗画面）。
5. 电脑上出现结果卡片，同时**已复制到电脑剪贴板**；手机继续显示书写画布，
   直接在 Word / Markdown / LaTeX 编辑器里 `Ctrl+V` 粘贴即可。

> 电脑端结果卡片：默认显示**渲染好的公式**，鼠标悬停切换成 **LaTeX 代码**。

### 想用鼠标直接写？

1. 点浮窗标题栏的 **「→鼠标」**（右键浮窗菜单、设置面板里也能切）。
   手机上会立刻出现「电脑端正在用鼠标手写，本页已暂停」的遮罩——**这是有意的**，
   免得手机一笔把鼠标写的内容盖掉。
2. 在浮窗的白色画板里**按住左键拖动**写公式，松开就是一笔；写错了点「撤销」。
3. 点「识别」（或先在设置里勾上「停笔后自动识别」），结果卡片出现、LaTeX 自动复制。
4. 点「**→手机**」切回去：手机端解除暂停，**手机原来写的内容一笔不少**；
   鼠标画板上的内容也留着，随时可以再切回来接着写。

## 两种书写模式

| | 手机手写（`phone`，默认） | 鼠标手写（`pc`） |
| --- | --- | --- |
| 谁在写 | 手机浏览器手指书写 | 电脑浮窗上鼠标书写 |
| 画布 | 手机画布 `doc` | 鼠标画板 `pc_doc` |
| 电脑端显示 | 取景可切：「填满窗口」（自动放大笔迹，默认）/「整块画板」 | **固定 1:1**，鼠标落在哪笔就写在哪，绝不自动缩放 |
| 手机端 | 可写、可识别、可撤销清空 | **自动暂停**（遮罩 + 按钮禁用 + 不发数据） |
| 送 AI 的图 | 裁掉四周留白 + 留边距（和电脑上看到的是同一块区域） | 同样裁留白，提示词改成「我用鼠标写的」 |
| 切换方式 | 标题栏「→鼠标 / →手机」、右键菜单、设置面板 | 同左 |
| 互不干扰 | 切模式**不清空**任何一方；两块画布内容互不可见、互不覆盖 | 同左 |

- 模式会记住（`config.json` 的 `input_mode`），下次启动还是上次那个模式。
- 鼠标手写时，**手机端的写入、识别、撤销请求都会被服务端拒绝**（不是只在界面上禁用），
  所以不会出现「两边同时写、互相覆盖」。
- 「停笔后自动识别」在两种模式下都有效（鼠标松开后开始计时）。
- 鼠标模式下画板是**一张固定的纸**：改窗口宽度后它会等比缩放并居中
  （四周露出深色底 = 画板边界）；「清空」之后画板会重新按当前窗口铺满。


## 界面与操作

### 手机端

| 元素 | 说明 |
| --- | --- |
| 顶部圆点 | 绿色 = 已连上电脑；红色 = 未连接（会每 1.5 秒自动重连） |
| 白色书写区 | 手指书写；**整块白色区域都能写**（白色区域 = 画板 = 送 AI 的范围），笔迹以约 5 次/秒的节奏同步到电脑 |
| 横屏 / 全屏书写 | 横屏自动收起工具，画板铺满页面；右上角「显示工具」可展开撤销、橡皮和识别，再点「全屏书写」收起。支持时同时进入浏览器全屏；不支持时仍可铺满网页可用区域 |
| 笔粗滑杆 | 1–10 档 |
| 擦笔画 | **笔画橡皮**：点或划过哪一笔，就整笔删掉（不会像涂抹橡皮那样留下缺口）；再点一次回到书写 |
| 撤销 / 清空 | 撤销上一笔 / 清空整幅 |
| 识别公式 | 提交识别（识别中会显示进度条） |
| 识别完成 | 结果在电脑显示；手机不弹出结果框、不显示复制按钮，也不自动改写手机剪贴板 |
| 暂停遮罩 | 电脑端切到**鼠标手写模式**时整页盖上「电脑端正在用鼠标手写，本页已暂停」，此时不能写、按钮禁用、数据也不再上传；电脑端切回来立刻恢复，**本地笔迹一笔不丢** |
| 「没连上电脑？点这里」 | 展开后手动填电脑地址（会跳转过去） |

横竖屏切换会保留已有笔迹，并重新铺满书写区；笔迹放不下时整体等比缩小和平移，不拉伸或裁掉公式。更新后刷新手机手写页即可使用。

### 电脑浮窗

浮窗很窄，所以**所有控制都挤在顶部标题栏里**（常驻显示，鼠标移上去不会跳动）：

| 元素 | 作用 |
| --- | --- |
| 标题文字 | 显示当前模式与笔数（手机：`airtex · 手机型号 · N 笔`；鼠标：`airtex · 鼠标手写 · N 笔`）；拖它 = 移动浮窗 |
| 「→鼠标 / →手机」 | **切换书写模式**：手机手写 ⇄ 鼠标手写（切到鼠标后手机端自动暂停） |
| 「识别」 | 识别当前模式画布上的手写 |
| 「清空」 | 清空**当前模式**的画布（手机手写时手机上也会一起清掉；鼠标手写只清鼠标画板） |
| 「撤销」 | 只在鼠标手写模式下出现：撤掉鼠标写的最后一笔 |
| 「二维码」 | 显示 / 隐藏扫码浮窗（浮窗右上角有 ✕，按 Esc 也能关）；鼠标手写模式下会收起（手机端已暂停） |
| 「▾ / ▴」 | **折叠 / 展开**：折叠后只剩这一条标题栏，不占地方；状态会记住 |
| 「设置」 | **打开 / 收起设置面板**：再点一次、点面板外面、按 Esc 都能关。面板摆在浮窗**旁边**，不压浮窗 |
| 右键浮窗 | 打开**菜单**（切换模式、二维码、折叠、复制地址、打开目录、退出） |
| 「✕」 | 退出 airtex |
| 单击画面（手机手写） | 识别当前手写（有结果卡片时先关掉卡片） |
| 拖左键（鼠标手写） | **写字**：按住左键拖动 = 一笔，松开即记入画板；有结果卡片时会先收掉卡片再落笔 |
| 画面取景（手机手写） | 默认「填满窗口」：把有笔迹的那块区域放大铺满浮窗（**和送 AI 的图是同一块区域**）；设置里可切「整块画板」：整块画板缩进浮窗，位置与手机画面一一对应。两种都不会把内容裁掉或画出画面。**鼠标手写固定 1:1，与这一项无关** |
| 右下角 **◢** | **按住左右拖动 = 改浮窗宽度**（宽度会记住） |
| 鼠标悬停结果卡片 | 在渲染好的公式与 LaTeX 代码之间切换 |
| `Esc` | 关掉打开的弹层（设置面板/菜单）；都没有时关闭结果卡片 |

**设置面板**（点标题栏「设置」）里可以：

- 切**输入模式**（手机手写 / 鼠标手写，两个按钮，当前模式高亮）
- 拖**不透明度**滑块（30%–100%，拖动时浮窗实时变化，松手即保存）
- 拖**浮窗宽度**滑块（也可以直接拖浮窗右下角的 ◢）
- 拖**鼠标笔粗**滑块（1–24，只影响鼠标手写）
- 开关**识别后自动复制到剪贴板**、**停笔后自动识别**
- 开关**显示整块画板**（只影响手机手写；勾上 = 与手机画面一一对应，不勾 = 填满窗口，笔迹更大）
- 填 **API Key** 并点「保存」

面板置顶、摆在浮窗旁边（左边放不下就放右边，都放不下就放下面），可以拖标题栏挪位置。
**点面板以外任何地方都会自动收起**：点浮窗、点别的程序、按 Esc、再点一次「设置」都行。
滑块是自绘的（蓝色已选轨道 + 白色圆形滑块），在深色面板上很显眼。

## 配置（`config.json`）

```json
{
  "api_key": "智谱开放平台的 Key",
  "base_url": "https://open.bigmodel.cn/api/paas/v4",
  "model": "glm-4.6v-flash",
  "fallback_model": "glm-4v-flash",
  "host": "0.0.0.0",
  "port": 8765,
  "token": "",
  "window_pos": null,
  "window_width": 560,
  "window_alpha": 0.88,
  "topmost": true,
  "input_mode": "phone",
  "canvas_view": "fill",
  "pc_pen_width": 4,
  "auto_copy": true,
  "show_qr_on_start": false,
  "auto_recognize": false,
  "auto_recognize_delay": 1800,
  "crop_margin": 28,
  "min_side": 64,
  "proxy": "",
  "temperature": 0.2,
  "timeout": 60,
  "max_side": 4096
}
```

| 键 | 说明 |
| --- | --- |
| `api_key` | 智谱开放平台（https://open.bigmodel.cn）申请的 Key，**不填也能跑通实时同步，只是不能识别** |
| `model` / `fallback_model` | 主模型和降级模型，都是免费模型；主模型拥堵（HTTP 429 错误码 13xx）时自动切换 |
| `port` | 服务端口，被占用时改这里（或看日志会提示） |
| `token` | 留空 = 局域网内任何人可连；填上随机串后，手机必须用带 `?t=xxx` 的地址（二维码会自动带上） |
| `window_alpha` | 浮窗不透明度，0.88 = 略透明；设为 1.0 完全不透明 |
| `window_width` | 浮窗宽度（像素） |
| `input_mode` | 启动时用哪种模式：`"phone"` = 手机手写（默认）；`"pc"` = 鼠标手写。界面上切模式会自动写回这里 |
| `canvas_view` | **手机手写**的取景：`"fill"` = 填满窗口（默认，和送 AI 的图同一块区域）；`"board"` = 整块画板（与手机画面一一对应）。鼠标手写固定 1:1，不受这一项影响 |
| `pc_pen_width` | 鼠标手写的笔粗（1–24，画板坐标单位；越粗识别越稳，太细可能看不清） |
| `auto_recognize` | `true` = 停笔 `auto_recognize_delay` 毫秒后自动识别 |
| `crop_margin` / `min_side` | 送入识别前裁剪四周留白、以及最小边长（太小会补白） |
| `proxy` | 留空 = 直连（忽略系统代理）；需要代理填 `"http://127.0.0.1:7890"` |

## 文件说明

| 文件 | 作用 |
| --- | --- |
| `app.py` | 主程序：半透明浮窗 + 鼠标手写画板 + 模式切换 + 启动服务 + 结果卡片 |
| `web.py` | HTTP/WebSocket 服务、手机页路由、两块画布的状态机、识别调度 |
| `web/index.html` | 手机端页面（手写画布 + 实时同步 + 识别状态 + 鼠标模式下的暂停遮罩） |
| `core.py` | 笔迹栅格化、GLM 视觉接口调用、LaTeX 规范化、剪贴板、配置、模式常量 |
| `qr.py` | 零依赖二维码生成器（手机扫码用；已用真实解码器验证） |
| `selftest.py` | 自检：`python selftest.py`（加 `--api` 会真连一次模型，加 `--gui` 会测浮窗界面） |
| `gui_check.py` | 浮窗界面自检：真的把窗口显示出来量尺寸，并真的发鼠标事件测鼠标手写 |
| `launcher.py` | 备用启动器（等价于 `run.bat`） |
| `airtex.log` | 运行日志（启动、连接、模式切换、识别、异常） |

## 自检

```
python selftest.py          # 离线全量检查（二维码/栅格化/协议/双模式分离/剪贴板…）
python selftest.py --api    # 额外真连一次模型，确认 Key 可用
python selftest.py --gui    # 额外检查浮窗界面（会短暂弹出浮窗，随后自动关闭）
python gui_check.py         # 只跑界面自检：结果卡片几何 + 鼠标手写端到端
```

`gui_check.py` 会**真的发鼠标事件**在浮窗上写一笔，然后核对
「鼠标点在哪、笔迹就落在哪」（1:1，没有被自动缩放挪位），以及
切模式时手机画布内容不丢、鼠标画板原地保留。

## 常见问题

- **手机打不开页面**：确认手机和电脑连的是**同一个 Wi-Fi**（不是手机流量）；
  确认 Windows 防火墙放行了 Python（首次运行会弹窗，选「允许」）；
  公司/校园网可能禁止设备互访，换成手机热点试试。
- **页面打开了但一直「未连接」**：看浮窗标题是否显示手机型号。若没显示，多半是
  地址里的 `?t=` 参数丢了（手动输入地址时容易漏），直接扫二维码最稳。
- **识别报 `HTTP 401`**：`api_key` 无效。右键浮窗 →「设置 API Key…」重新填。
- **识别报 `HTTP 429 / 1305`**：免费模型高峰期过载，工具会自动降级到 `fallback_model`
  重试；两个都拥堵时稍等再试。
- **识别结果不准**：字写大一点、笔画分开、一行写完别太挤；复杂公式可以分几次识别。
  也可以在 `config.json` 的 `prompt` 里补充你自己的要求。
- **结果卡片只显示代码、不显示公式**：本机没有可用的 LaTeX 渲染器（TeX 或 matplotlib）。
  装了 TeX Live 或 `pip install matplotlib` 即可；不影响复制代码。
- **想换其它视觉模型**：改 `config.json` 的 `base_url` / `model` / `api_key` 即可，
  任何 OpenAI 兼容的视觉接口都行（详见 `tex/README.md` 里的对照表）。
- **手机端笔迹和电脑不同步**：页面切后台会被系统限流，切回来会自动追平；
  手机页面刷新后会自动把电脑上已有的内容接回来，不会丢。
- **手机写的东西突然消失**（已修）：v4 协议下服务端不再把手写内容回推给
  正在书写的那个客户端，只有「电脑端点清空」和「电脑端重启」会覆盖手机画面。
- **手机画板可以继续向外写**：单指书写，两指缩放或平移无限画布，
  初始视野之外也能写；横竖屏切换不再重排笔迹。「查看全部」可找回全部内容。
  「框选」默认可沿任意轨迹画自由套索，松手自动闭合，选中整笔笔迹后可拖动圈内移动；
  左上角可切换自由套索/矩形并记住选择，移动与擦除均可撤销。
- **电脑上看不全手机上写的内容 / 笔迹跑到画面外**（已修）：以前电脑端按文档比例
  出图（竖屏手机 1000×1750 → 图比画布区高一倍多），被浮窗裁掉上下两端；
  结果卡片出现、画布区变矮时也没有重画。现在笔迹图一律按**画布区当前实际尺寸**
  绘制，并等比缩放把内容完整放进去：不裁、不溢出。想看整块画板（与手机一一对应）
  可在设置里勾「显示整块画板」。
- **第一次识别出公式时，卡片只露出上半部分**（已修）：结果卡片是「先占位、后渲染」
  的——公式图还在后台渲染时卡片只有一行高，画布区按这个高度让位，等图贴上来
  就被窗口截掉了（拖一下右下角 ◢ 改宽度才会重排、恢复正常）。现在公式图渲染好、
  悬停切换公式/代码视图、折叠展开之后都会重新排一次版；卡片实在太高时会整体
  长高窗口而不是裁掉卡片。回归测试见 `python gui_check.py`。
- **手机上写不了 / 一写就弹出「本页已暂停」**：电脑端现在在**鼠标手写模式**。
  这是刻意的：两种模式各用一块画布，手机这时写会和鼠标抢同一块画布。
  在电脑浮窗标题栏点「→手机」即可切回，手机原来写的内容一笔都不会少。
- **鼠标写的时候画面会跟着动 / 笔迹跑偏**（不会发生）：鼠标手写固定 1:1 画板，
  不做「填满窗口」那种自动取景缩放；有结果卡片时落笔会先把卡片收掉，
  画布区高度恢复后再落笔，所以落笔点永远和鼠标位置一致。
- **鼠标手写时画板没铺满窗口**：画板是一张固定大小的「纸」——改了窗口宽度后它会
  等比缩放居中（四周露深色底 = 边界）。点「清空」后画板会按当前窗口重新铺满；
  已有笔迹时不会自动改尺寸（免得把写好的内容挪歪）。
- **设置面板挡住浮窗、点别处关不掉**（已修）：以前面板正贴在浮窗右上角、把标题栏
  （包括「设置」按钮）盖住，而且它是置顶的独立小窗口，Tk 不会因为「失焦」自动关，
  只能点它自己的 ✕。现在面板摆在浮窗**旁边**（左边放不下放右边、再放下面），
  并且**点面板以外任何地方都会收起**：点浮窗、点别的窗口/别的程序、按 Esc、
  再点一次「设置」都行（右键菜单同理）。回归测试见 `python gui_check.py`。
- **端口被占用**：启动时会有弹窗提示，把 `config.json` 的 `port` 改成 8766 之类即可。
- **退出**：右键浮窗 →「退出 airtex」，或点标题栏的「✕」。

## 隐私与费用

- 手写内容只在你自己的电脑和手机之间通过局域网传输，**不经过第三方**。
- 只有点「识别公式」时，才把**当前这一幅笔迹渲染成 PNG** 上传给智谱接口；图片不落盘
  （除非把 `debug_keep_png` 设为 `true`）。
- 默认模型 `glm-4.6v-flash` / `glm-4v-flash` 是智谱标注的**免费模型**，调用不扣余额；
  每次识别用的真实模型名记录在 `airtex.log`，也会显示在电脑的结果卡片上。

## 技术说明

- **零第三方依赖**：只用 Python 标准库 + Pillow。WebSocket 服务端、二维码生成器都是
  自己实现的（`web.py` / `qr.py`），不需要 `pip install websockets/qrcode`。
- **两套画布，各写各的**：`AppCore` 里 `doc`（手机）和 `pc_doc`（鼠标）是**两个独立
  文档**，各自有自己的版本号（`rev` / `pc_rev`）。切模式只改「谁在写」：
  * 鼠标模式下手机端的 `/api/update`、`/api/recognize`、`/api/undo` **一律被拒绝**
    （不是靠界面禁用），并且 `snapshot()` 里只回手机画布，手机端根本拿不到鼠标笔迹；
  * 「清空」只清当前模式那块画布，`cleared_seq` 只在手机画布被清时才 +1，
    所以切模式来回折腾也不会误清对方；
  * 识别结果带 `mode` 标记，手机端只处理 `mode == "phone"` 的状态和报错，结果在电脑端显示。
- **鼠标手写为什么用 `tk.Canvas`**：手机手写是「服务端栅格化成 PNG → 贴到 Label」，
  那种画法每加一个点都要重画整幅图；鼠标书写要跟手，所以直接用画布元素
  （一条线 = 一笔，加一个点只改 `coords`），松手时才写进 `pc_doc`。
  画板按 1:1 映射（文档坐标 = 画布像素，`_pc_map`），窗口改宽后等比缩放居中，
  落笔点坐标反算后再夹进画板范围。
- **实时同步**：优先走 WebSocket（`/ws`），失败自动退回 HTTP 轮询（`/api/state`）。
  同步协议要点（v4 起，v5 加了模式字段）：手机是手机画布的唯一来源，服务端只存储+转发，
  **绝不把内容回推给刚写入的那个客户端**（改为回一个 `ack` 告知版本号），
  因此不会出现「写一笔被自己的旧帧覆盖」；客户端也**不会**因为
  「笔迹变少」而丢弃写入，所以擦除、撤销都能正常同步。
  v5 起状态里多了 `mode`，手机端据此显示「暂停」遮罩并停止发送。
- **二维码可靠性**：`qr.py` 的块表/对齐表/格式信息/版本信息都经过三方交叉校验
  （ISO 总码字数、预留区实现、自解码回读），并用 OpenCV 的真实解码器端到端验证过。
- **识别与呈现**完全沿用 `tex/latex_ocr.py` 的方案：同样的提示词规则（`$...$` / `$$...$$`）、
  同样的分隔符修正、同样的免费模型与自动降级、同样的 TeX 优先渲染。
  只在提示词里按模式改一句「我在手机上手写了…」/「我在电脑上用鼠标手写了…」。
- **手机无限画布与视角独立**：v7 文档带 `infinite: true`，`doc.w/h` 只表示初始视野，
  笔迹使用世界坐标，支持负值和初始视野之外的位置。两指操作仅改变本地视角，
  旋转、工具栏和结果面板变化不改写笔迹；框选移动才改变笔迹坐标。
  电脑「填满窗口」及识别裁到全部笔迹，「整块画板」取初始画板与笔迹的并集，
  输出图片仍限制最长边，不按无限坐标范围分配巨型位图。旧版有限画板仍夹住坐标。
  可运行 `node tests/airtex-infinite.cjs` 与 `node tests/airtex-mobile.cjs`
  验证手势、框选移动、同步、旋转和电脑预览（不调用外网识别）。
- **鼠标画板是另一份文档**：尺寸 = 进入鼠标模式时的画布区大小（`pc_set_board`），
  空板时跟着窗口走、有笔迹就不动，因此不会边写边被重新取景。
