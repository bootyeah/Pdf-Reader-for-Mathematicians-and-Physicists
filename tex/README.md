# 快捷 LaTeX 公式识图工具

后台常驻 + 全局热键呼出框选：框选屏幕任意区域的公式 → 视觉大模型识别 →
**渲染好的公式直接显示在框选矩形内**（简洁卡片浮层，可拖动；悬停切换 LaTeX 代码），代码自动复制到剪贴板。

## 快速开始

1. 双击 `run.bat`：工具进入后台常驻，**屏幕角落会出现一个常驻小悬浮球**（看到它 = 工具正在运行；默认右下角，可拖动，位置会被记住），几秒后启动提示消失，悬浮球一直在。
2. 打开你要识别的页面（PDF / 网页 / 论文等），随便停留在任何窗口。
3. 按 **Ctrl+Alt+Z**（全局热键，任何窗口下都有效）：屏幕变暗，按住鼠标左键拖拽框选公式，松开自动识别。
4. 识别结果直接出现在你框选的矩形内：默认显示**渲染好的公式**，鼠标悬停切换为 LaTeX 代码；代码已自动复制到剪贴板。
5. 按 **Esc** 关闭结果框；再按 **Ctrl+Alt+Z** 继续框选下一张。
6. 按 **Ctrl+Alt+X** 退出工具。

| 拖动结果框 | 移动结果框位置 |

| 元素 | 说明 |

## 文件说明

| 文件 | 作用 |

| `latex_ocr.py` | 主程序（后台常驻 + 全局热键 + 截屏 + 识别 + 框内显示） |

## 配置（config.json）

```json
{
  "api_key": "你的 API Key",
  "base_url": "https://open.bigmodel.cn/api/paas/v4",
  "model": "glm-4.6v-flash",
  "fallback_model": "glm-4v-flash",
  "hotkey": "ctrl+alt+z",
  "exit_hotkey": "ctrl+alt+x",
  "pill_pos": null,
  "prompt": "……",
  "proxy": "",
  "temperature": 0.2,
  "timeout": 60,
  "max_side": 4096
}
```

- `api_key`：智谱开放平台（https://open.bigmodel.cn）申请的 Key。
- `base_url` / `model`：接口地址和模型名，可换成任意 OpenAI 兼容的视觉服务。
- `fallback_model`：**降级备用模型**。主模型返回 HTTP 429（例如错误码 1305「该模型当前访问量过大」平台过载、1302 账户速率限制）时，自动改用它重试一次，识别不会因为平台拥堵而失败；切换记录写入 `latex_ocr.log`（「主模型 … 拥堵，自动降级到 … 重试」）。留空 `""` = 关闭自动降级。鉴权/参数类错误（401、400）不会触发降级，以免掩盖真正的配置问题。
- `hotkey` / `exit_hotkey`：全局热键。支持 `ctrl` / `alt` / `shift` / `win` + 单个字母、数字或 F1-F12，用小写 `+` 连接，例如 `"ctrl+shift+q"`、`"alt+f9"`。修改后需重启工具生效。
- `pill_pos`：悬浮球位置 `[x, y]`，`null` 表示自动（主屏右下角）；拖动悬浮球后会自动写入，无需手动改。
- `prompt`：识别提示词。当前规则：简单单行公式用 `$...$`；矩阵、多行、积分求和等复杂公式用 `$$...$$`；禁止 `\[...\]`；只输出代码本身。可按需修改。
- `proxy`：留空 = 直连（忽略系统/环境变量里的代理设置）。需要走代理时填完整地址，例如 `"http://127.0.0.1:7890"`。
- `temperature`：越低输出越稳定，建议 0~0.3。
- `max_side`：图片最长边超过该像素值时等比缩小后再上传。

## 费用与额度

- 本工具默认使用 **GLM-4.6V-Flash**（备用 `glm-4v-flash`），两者都是智谱开放平台标注的**免费模型**，调用**不扣余额**，账单不会出现费用；每次识别使用的真实模型名记录在 `latex_ocr.log`（「识别完成（服务器模型：…）」）。
- 免费模型**没有"超出后自动转付费"的机制**：它按**速率/并发限制**管理，超出限制只会**限流或报错**，不会自动扣费；付费模型（如 `glm-4.6v-flashx`、`glm-4.6v` 等）是单独的模型名，需要手动改 `config.json` 的 `model` 才会用到，且要求账户有余额。
- 免费模型在高峰期可能返回 **HTTP 429 / 错误码 1305**（「该模型当前访问量过大」，属于**平台过载**，与你的账户行为无关）：此时工具会按 `fallback_model` **自动降级**重试，你一般无感。规则详见 https://docs.bigmodel.cn/cn/api/rate-limit ，各模型的实际速率可在 https://bigmodel.cn/usercenter/proj-mgmt/rate-limits 查看。

## 更换其它视觉模型（示例）

换模型**不用改任何代码**：只需编辑 `config.json` 里的 `base_url` / `model` / `api_key`（必要时改 `prompt`、`temperature`），保存后重启工具即可。

| 服务 | base_url | model |
| --- | --- | --- |
| 智谱（默认） | `https://open.bigmodel.cn/api/paas/v4` | `glm-4.6v-flash`（备用 `glm-4v-flash`） |
| 硅基流动 DeepSeek-VL2 | `https://api.siliconflow.cn/v1` | `deepseek-ai/deepseek-vl2` |
| 阿里云百炼 Qwen-VL | `https://dashscope.aliyuncs.com/compatible-mode/v1` | `qwen-vl-max` |
| OpenAI | `https://api.openai.com/v1` | `gpt-4o-mini` |

> 说明：DeepSeek 官方 API（api.deepseek.com）目前只有纯文本模型，不支持图片输入，
> 想用 DeepSeek 识图走硅基流动等云平台的 DeepSeek-VL2。智谱等国内服务不需要外网。

## 常见问题

- **按热键没反应**：热键可能被其它程序占用，工具会自动尝试备选热键（框选：`ctrl+shift+z`、`alt+f9`、`ctrl+alt+q`；退出：`ctrl+shift+x`）并在右下角提示；**任何时候都可以直接点击右下角悬浮球来框选**；也可自己修改 `config.json` 的 `hotkey` 后重启。
- **看不到悬浮球**：说明工具没在运行，双击 `run.bat` 重新启动即可。
- **Esc 没反应**：本工具把 Esc 做成临时全局热键——框选遮罩/结果框出现时自动生效、关闭时自动释放，不依赖键盘焦点；若仍无效，看 `latex_ocr.log` 里是否有「Esc 热键注册失败」。
- **公式渲染不出来（只显示代码）**：渲染依赖本机 TeX（`latex` + `dvipng`，TeX Live 自带）；没有 TeX 时自动尝试 matplotlib 的 mathtext（能力有限，复杂公式可能失败）；都不行则退化为显示代码。可看 `latex_ocr.log` 里的「TeX 渲染失败」记录排查。
- **分隔符自动修正**：若模型返回的代码没有用 `$`/`$$` 包裹（或用了 `\[...\]`），工具会自动统一成 `$...$` / `$$...$$`，修正记录在 `latex_ocr.log`（「分隔符已自动修正」）。
- **账单没扣费 / 看不到 token 消耗**：`glm-4.6v-flash`（及备用 `glm-4v-flash`）是智谱的免费模型，调用不扣余额；用量可在 open.bigmodel.cn「用量明细」里查看（数据有延迟）。每次识别实际使用的模型会记录在 `latex_ocr.log`（「识别完成（服务器模型：…）」一行），也可用 `python selftest.py` 直接看服务器返回的模型名。
- **提示“工具已经在后台运行中”**：说明已有一个实例在运行，直接按热键使用即可；若找不到它，用任务管理器结束 `pythonw.exe` 后重新双击 `run.bat`。
- **报 HTTP 401**：`config.json` 里的 `api_key` 无效或复制不完整。
- **报 HTTP 429（错误码 1305「该模型当前访问量过大」）**：属于智谱**平台过载**，与你账户的调用频率无关（账户限流是 1302），免费模型在高峰期较常见。工具默认会按 `fallback_model` **自动降级**重试，因此通常不会报到你面前；若两个模型都拥堵才会失败，稍后重试即可（官方也建议「增加重试间隔，避免立即高频重试」）。想提升稳定性可把 `model` 换成付费的 `glm-4.6v-flashx`（约 $0.04/百万 token 输入）。
- **报 `ConnectionRefusedError [WinError 10061]`（目标计算机积极拒绝）**：本机环境变量
  `HTTP_PROXY` / `HTTPS_PROXY` 指向了一个没在运行的代理软件（常见 `127.0.0.1:7890`，
  如 Clash 未启动）。本工具默认直连、忽略这些环境变量，一般即可解决；
  若你确实需要走代理，在 `config.json` 里设置 `"proxy"` 并确保代理软件已启动。
  想彻底清理，可在 Windows「系统属性 → 环境变量」里删除 `HTTP_PROXY` 和 `HTTPS_PROXY`。
- **报网络错误**：检查能否打开 https://open.bigmodel.cn ，或换 `base_url`。
- **程序退不掉**：按 Ctrl+Alt+X；若热键失效，用任务管理器结束 `pythonw.exe`。
- **截屏位置偏移**：一般是 Windows 缩放引起，工具已自动开启 DPI 感知；如仍偏移，
  请把系统缩放设为 100% 后重试。
- **识别结果不准**：框选时尽量只框公式本身、留少量边距；可在 `prompt` 里补充要求。
- **多显示器**：遮罩覆盖全部屏幕（虚拟桌面），副屏也能框选。
